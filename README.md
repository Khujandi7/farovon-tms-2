# FAROVON TMS 2.0

Система управления обучением ГК «Фаровон». Единственный источник истины — база данных PostgreSQL (Supabase). Excel и Google-таблицы только импортируются.

## Что сделано (Фаза 1: архитектура и база данных)
- `supabase/migrations/0001_types_and_core.sql` — таблицы, типы, ограничения.
- `supabase/migrations/0002_functions_and_triggers.sql` — расчёты (деньги, курс, участники, человеко-часы, внеплановые, досье), проверки, аудит.
- `supabase/migrations/0003_rls.sql` — права по ролям ADMIN, ACADEMY_MANAGER, HR, FINANCE, VIEWER.
- `supabase/tests/phase1_tests.sql` — 44 проверки, `supabase/tests/run_local.sh` — запуск на локальной базе.

## Главные правила
1. Деньги считает только база. Сумма в сомони (`amount_tjs`) и курс записываются триггером, с сайта их менять нельзя.
2. Нет курса — ошибка, а не курс 1.
3. План года = единственная версия бюджета со статусом APPROVED. Отменённая «Оптимизация» не учитывается.
4. Тренинг может проходить в несколько заходов (`training_sessions`), расход записывается один раз.
5. Плановое/внеплановое: `trainings.source_type`; у внепланового заявки нет, и это не ошибка.

## Как запустить проверки (технический шаг, для разработчика)
`bash supabase/tests/run_local.sh` — поднимет временную базу, применит миграции и выведет PASS/FAIL по каждой проверке.
